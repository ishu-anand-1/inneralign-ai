# 🧠 InnerAlign AI

AI-Powered Handwriting Analysis Platform

InnerAlign AI analyzes handwritten text images and extracts handwriting features to provide insights into writing patterns, emotional indicators, image quality, and overall handwriting consistency.

---

## 🚀 Features

### ✍️ Handwriting Feature Extraction

* Slant Angle Detection
* Baseline Consistency Analysis
* Stroke Pressure Estimation
* Letter Spacing Measurement
* Word Spacing Analysis
* X-Height Variation Detection
* Loop Openness Analysis
* Writing Speed Estimation

### 🤖 AI Emotion Analysis

* Happy / Positive
* Calm / Neutral
* Stressed
* Anxious
* Sad / Low Mood

### 📊 Quality Assessment

* Blur Detection
* Brightness Analysis
* Contrast Evaluation
* Alignment Detection
* Blank Page Detection

### 📈 Confidence Scoring

* Image Quality Score
* Feature Confidence Score
* Emotion Confidence Score
* Overall Analysis Confidence

### 📄 Reporting

* Detailed Feature Analysis
* Emotion Insights
* Quality Feedback
* Improvement Suggestions
* Downloadable PDF Reports

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ishu-anand-1/inneralign-ai.git

cd inneralign-ai
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend:

```bash
http://localhost:5173
```

---

## Backend Setup

```bash
cd inneralign-ml-backend
```

Create Virtual Environment:

```bash
python -m venv venv
```

Activate:

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install Dependencies:

```bash
pip install -r requirements.txt
```

Run Backend:

```bash
python app.py
```

Backend:

```bash
http://localhost:5000
```

## API Endpoints

### Health Check

```http
GET /health
```

Response:

```json
{
  "status": "OK"
}
```

---

### Analyze Handwriting

```http
POST /analyze
```

Form Data:

```text
image : Handwritten Image
```

Response:

```json
{
  "overallConfidence": 82.4,
  "emotion": "Happy / Positive",
  "emotionConfidence": 76.2,
  "qualityScore": 91.4,
  "features": []
}
```
